# Template Padrão da Aplicação

O website da **Ambrozini** foi desenvolvido utilizando **HTML5**, **CSS3** e **JavaScript (ES6+)**, priorizando desempenho, organização do código e responsividade para diferentes dispositivos.

A aplicação possui três áreas principais:

- **Restaurantes e Delivery**;
- **Eventos**;
- **Página institucional do CEO Pedro Ambrozini**.

Todas as páginas compartilham componentes padronizados, como menu de navegação e rodapé, garantindo consistência visual durante toda a experiência do usuário.

## Identidade Visual

O projeto segue o Manual de Identidade Visual da Ambrozini, utilizando os seguintes elementos:

- **Cor Primária:** Marrom (#52302C);
- **Cor Secundária:** Off-white (#F5F1EB);
- **Cor de Destaque:** Amarelo (#E1AD01);
- **Cor de Apoio:** Azul institucional (#008080).

### Tipografia

- **Fonte Institucional:** Avory PE Variable;
- **Fonte Secundária:** AMSI Pro Condensed Bold;

## Responsividade

O layout foi desenvolvido utilizando **CSS Media Queries**, adaptando automaticamente a interface para computadores, tablets e smartphones.

A estrutura foi planejada com foco em usabilidade, reorganizando os elementos conforme o tamanho da tela, preservando a experiência do usuário em qualquer dispositivo.

## Componentes da Interface

O website possui componentes reutilizáveis entre as páginas, tais como:

- Menu de navegação responsivo;
- Rodapé institucional;
- Botões de ação (CTA);
- Galeria de imagens;
- Janelas modais para apresentação dos tipos de eventos;
- Formulário de contato e captação de leads;
- Mapa integrado utilizando Google Maps;
- Links para WhatsApp, iFood e redes sociais.

O código-fonte do projeto encontra-se organizado em módulos separados para HTML, CSS e JavaScript, permitindo maior facilidade de manutenção e futuras expansões da aplicação.

## Identidade da Marca

O layout foi desenvolvido seguindo a identidade visual da Ambrozini, buscando transmitir profissionalismo, credibilidade e sofisticação.

A predominância da cor marrom reforça a tradição e a gastronomia, enquanto o off-white proporciona leveza e elegância. O amarelo é utilizado para destacar ações importantes e chamadas para conversão, e o azul complementa a identidade visual, trazendo equilíbrio à composição.

Toda a interface foi projetada para valorizar imagens dos restaurantes, operações de eventos e experiências gastronômicas, fortalecendo o posicionamento institucional da marca.
